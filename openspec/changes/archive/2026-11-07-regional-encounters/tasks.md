## P1 implementation checklist

- [x] Regional expression: multiple functional hot/cold variants, compatible mixed ecologies, stable old ships.
- [x] Alien behavior: backwards pilgrim, pendulum gazer and seam-runner, each with warning, commitment, recovery and distinct motion.
- [x] Coordination: optional nest/relay, visible links, staggered threats, interruptible support and readable collapse.
- [x] Useful rewards: ship-local capabilities, preview, one claim per eligible player, guidance to try earned tools safely.
- [x] Tension and release: quiet arrival/staging spaces, small trace encounters, hordes and optional challenges.
- [x] Small stories: local actions connected to physical evidence with persistent visible consequences.
- [x] Verification: native, separate gameplay/build comparisons, unit coverage >=95% overall/per source, sanitizers, browser/smoke and target builds.
- [x] Documentation/specification and reproducible human checkpoints.

Publication follows the validated main commit through the repository workflow; its status is reported in the user handoff.
